# typwriter-autotyper
just a simple autotyper to do the typewriter things

## features
- ghost mode - allows you to press random keys the program than translates them to the real needed ones or if you have mistake rate enabled it presses the wrong key
- speed up to 100k/10min - allows you to do a lection in realistic speed or in down to 1 second per lection
- mistake rate - allows you to get a specific mistake rate over the lection
- hide mode - allows you to hide the gui with a key combo and make it visibale again if you need it if it is invisable the programm still runs
